업데이트 방식

GitHub Actions가 매주 월요일 06:00(KST)에 data.go.kr을 확인해 새 분기가 나오면 내려받고 집계한 뒤 이 저장소에 커밋합니다. GitHub Pages가 그 커밋을 자동 배포합니다. 별도 서버도, 월 비용도 없습니다.

이해해야 할 한계

  • 분기 스냅샷입니다. 각 분기 시점의 영업 중 업소만 담고 있어, 이 데이터만으로 폐업률을 계산할 수 없습니다. 증감은 같은 업소번호(상가업소번호)를 기준으로 분기 간 비교해야 합니다.
  • 브랜드 수치는 추정입니다. 편의점·카페·치킨 브랜드 점유율은 상호명에 포함된 문자열을 규칙으로 매칭한 값이라 실제 점포 수와 다릅니다. 참고용으로만 쓰세요.
  • 반경 밀도는 근사입니다. 2km 격자로 미리 뭉어 둔 값이라 격자 경계를 넘는 오차가 있습니다. 정확한 값이 필요하면 원본 CSV로 직접 집계해야 합니다.
  • "소상공인"만 있는 데이터가 아닙니다. 프랜차이즈·대형점·임대점포 등도 함께 집계되므로 실제 소상공인 수와 차이가 있습니다.
  • 인구는 주민등록 기준입니다. 실제로 살면서 전입신고를 하지 않은 사람은 집계되지 않습니다. 유동인구가 많은 지역에서는 실제 체류 인구보다 적게 나옵니다.

다시 만들기

로컬에서 전체 파이프라인을 다시 돌리려면:

pip install duckdb pandas requests lxml html5lib
python scripts/refresh.py

첫 실행은 353MB ZIP 다운로드 때문에 몇 분 걸립니다.
